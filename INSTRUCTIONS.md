# How to Use

A very simple guide. No technical knowledge needed.

## What does this program do?
It makes your virtual computer look like a real computer, so games and
programs treat it as real hardware instead of a virtual machine.

## Before you start
- Close all your virtual machines.
- You must be able to allow the program to make changes on your computer
  (a permission window will pop up — click **Yes**).

## Steps
1. Double-click the program to open it.
2. If a permission window appears, click **Yes**.
3. The program finds your VMware by itself. If it does not, click
   **Browse** and choose the VMware folder.
4. Choose what you want:
   - **Full spoof** — changes everything (recommended).
   - **GPU only** — changes only the graphics card.
5. Click **Install patch** and wait a moment.
6. When the status turns green (**OK**), you are done.
7. Open VMware and start your virtual machine as usual.

## What the buttons do
- **Install patch** — applies everything at once.
- **Only .exe** / **Only EFI** — applies just one part.
- **Generate driver** — prepares a graphics driver in a new folder
  next to the program.
- **Verify** — checks that everything is correct.
- **Restore** — puts back the original files if you want to undo.
- **Configure VM** — makes your virtual machine settings safer from
  detection.

## Good to know
- The program saves a backup by itself before changing anything.
- If something looks wrong, click **Restore** to go back to normal.
- Keep VMware closed while installing.
