# Instrucciones de uso

Una guía muy sencilla. No hace falta ningún conocimiento técnico.

## ¿Qué hace este programa?
Hace que tu computadora virtual se vea como una computadora real, para que
los juegos y programas la traten como hardware de verdad y no como una
máquina virtual.

## Antes de empezar
- Cierra todas tus máquinas virtuales.
- Debes permitir que el programa haga cambios en tu computadora
  (aparecerá una ventana de permiso — pulsa **Sí**).

## Pasos
1. Haz doble clic en el programa para abrirlo.
2. Si aparece una ventana de permiso, pulsa **Sí**.
3. El programa encuentra tu VMware solo. Si no lo encuentra, pulsa
   **Examinar** y elige la carpeta de VMware.
4. Elige lo que quieres:
   - **Full spoof** — cambia todo (recomendado).
   - **GPU only** — cambia solo la tarjeta gráfica.
5. Pulsa **Instalar patch** y espera un momento.
6. Cuando el estado se ponga verde (**OK**), ya está listo.
7. Abre VMware y enciende tu máquina virtual como siempre.

## Qué hace cada botón
- **Instalar patch** — aplica todo de una vez.
- **Solo .exe** / **Solo EFI** — aplica solo una parte.
- **Generar driver** — prepara un controlador de gráficos en una carpeta
  nueva junto al programa.
- **Verificar** — revisa que todo esté correcto.
- **Restaurar** — devuelve los archivos originales si quieres deshacer.
- **Configurar VM** — hace que los ajustes de tu máquina virtual sean más
  difíciles de detectar.

## Cosas que conviene saber
- El programa guarda una copia de seguridad por su cuenta antes de cambiar nada.
- Si algo se ve mal, pulsa **Restaurar** para volver a la normalidad.
- Mantén VMware cerrado mientras instalas.
